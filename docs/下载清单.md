## 💡 下载加速小贴士

```bash
# 如果 GitHub 直连慢，可以试镜像站（把域名换掉即可）：
#   https://ghproxy.net/https://github.com/...
#   https://gitclone.com/github.com/...
# 例如：
git clone --depth 1 https://ghproxy.net/https://github.com/blacckoscar/SOCIAL-ALGORITHM.git

# 只想要某个文件，用 curl 直下 raw：
curl -O https://raw.githubusercontent.com/<owner>/<repo>/main/README.md
```

> 提醒：国内镜像站的稳定性随时变化，下载失败时换一个再试。
