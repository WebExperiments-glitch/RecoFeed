# 噪声标签表（一行一个词，# 开头为注释）
#
# 为什么必须有：
#   画像里出现过 support 0.33 / install 0.17 / https 0.12 / easily 0.11 / version 0.12
#   / actions 0.12 / good 0.11 / practices 0.11 / demo 0.15 / list 0.15 / awesome-list 0.15
#   这类标签 —— 它们是 README 套话和 GitHub 上被滥用的通用 topic，
#   既不代表技术兴趣，还会被当成爬虫查询词（去 GitHub 搜 "support"）污染语料库。
#
# 判定原则：
#   ① 出现在 README 模板句里（install / usage / license / contribution…）
#   ② 通用到无法指向任何技术方向（good / easily / version / tools…）
#   ③ 网络与元信息（https / url / api-key 除外 —— api 本身有意义）
#   ④ 收录类词（awesome-list / list / collection / curated…）—— 它描述的是"这是个清单"，
#      不是"这个清单讲什么"
#
# ⚠️ 不要往这里加真正的技术词：ai / llm / tts / rvc / python / database / security
#    这些虽然泛，但确实指向技术方向，属于有效兴趣维度。
