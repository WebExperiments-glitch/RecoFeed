# 自定义停用词表（纯文本，一行若干词，# 开头为注释）
#
# 为什么必须有：
#   jieba 自带的 STOP_WORDS 只有约 30 个英文词（the/of/is/and/to...），
#   中文停用词一个都没有，会把"的""我们""可以"等高频词当作关键词。
#
# 覆盖范围：中文虚词 + README 套话 + 英文语法词 + 中文语法词 + 切词碎片
#
# 实测根因：jieba 的 TF-IDF 只做词频统计，不给词性/领域加权。
#   结果 running / large / Simple / Get / up 和 inference / GGUF
#   拿到完全相同的权重（都是 0.2717），全部灌进 tags_json。
#
# 保守收词：只收"在任何技术语境下都不表方向"的通用词。
#   不要收 string / index / memory / server / language / data / type
#   它们在具体仓库里是有效标签（pgvector 的 index、sqlite 的 memory）。
#   不要收 推理 / 生成 / 训练，它们在具体仓库里是有效方向词。
